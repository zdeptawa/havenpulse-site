About

Haven Pulse is building simple tools for monitoring the places and conditions you care about — without requiring you to constantly check them yourself.

NotiWatch

NotiWatch is an event monitoring and notification platform currently in development.

It monitors external sources such as severe weather alerts, along with optional remote monitoring devices that can report environmental conditions, connectivity, and power status.

Currently in development

NotiWatch is currently being prototyped and tested with remote monitoring devices and real-world alerting scenarios.
